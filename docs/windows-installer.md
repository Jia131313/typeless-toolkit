# Windows 安装版与运行环境

Windows 提供内置 Node 与 Lite 两种安装版，并保留两种 ZIP；下载请以 Release 实际附件为准。

## 选择发行形式

| 形式 | Node 来源 | 数据位置 |
| --- | --- | --- |
| 安装版（内置 Node） | 随工具集维护的 Node 24 LTS | `%LOCALAPPDATA%\TypelessToolkit\data` |
| 安装版（Lite） | 本机可用的 Node | 同上 |
| Portable ZIP | ZIP 内置 Node | 解压目录的 `data` |
| Lite ZIP | 本机可用的 Node | 解压目录的 `data` |

安装附件后缀为 `win-x64-portable-setup.exe` 和 `win-x64-lite-setup.exe`；ZIP 附件保留。安装版默认安装到当前用户的 `%LOCALAPPDATA%\Programs\TypelessToolkit`，不要求全用户安装。两个安装版共用安装身份；切换到 Lite 会移除程序目录的内置 Node，但不删除用户数据。卸载保留数据。

安装包暂未签名，Windows 可能显示未知发布者。不要以关闭系统安全检查作为安装步骤。Windows 仍需 WebView2 Runtime。

推荐日常使用内置 Node 安装版：运行时随工具集更新，不需要另行维护系统 Node。Lite 仍适合已有受支持 Node 且愿意维护该环境的用户，两者不因名称区分为不同功能等级。

安装向导提供简体中文和英文，使用工具集图标并跟随 Windows 明暗外观。欢迎页注明发行类型；目录页区分程序与数据位置，完成页说明旧 ZIP 数据迁移入口。如提示工具集仍在运行，请从托盘退出工具集，不需要关闭 Typeless 本体。

## Lite 的 Node 要求

基本运行要求为 Node 22.12+，推荐 Node 24 LTS。Lite 不安装、升级系统 Node，也不修改 PATH；从官网安装的 Node 不会自行更新。

安装前和启动时复用宿主的 Node 探测：检查候选路径、版本、是否可运行以及实际 `node:sqlite` 能力。优先使用满足基本要求且具备 SQLite 的候选；只有基本运行资格时可以使用基础功能，但自动切号的限制会明确显示。内置版只使用包内 Node，不改用系统 Node。

“设置”显示当前进程实际使用的 Node 路径、来源、版本和 SQLite 能力。SQLite 可用不等于自动切号必然可用，后者还需要能读取 Typeless 数据库和听写状态。正在听写时禁止切号的行为保持不变。

## 从旧 ZIP 迁入

首次安装且目标没有账号、词库或登录快照时，可在设置中选择旧 ZIP 工具集目录，预览账号数、词条数和迁移体积后确认。先从托盘完整退出旧工具集；新工具集确认迁移后也会完整退出，迁移完成后重新启动。

迁入账号、主词库、必要配置、登录快照和同步协调记录，并改写旧数据目录内的配置路径。不迁入历史备份、日志、缓存或更新包，不删除旧目录。目标已有业务数据时使用现有备份导入，不再提供一套迁移合并规则。

## 更新与排错

安装版下载同类型 Setup，校验后由用户点击“退出并安装”，启动可见安装器，再完整退出工具集。安装器不会关闭 Typeless 本体或其他 Node 进程。安装完成不直接等同升级成功：新工具集启动并核对目标版本后才记录成功。取消安装保留原数据。

ZIP 仍使用原自替换路径，本轮修正 PowerShell 5.1 读取中文 UTF-8 版本文件的编码问题。安装版不使用 ZIP 替换脚本。

GitHub 限流时显示原因及可重试时间，等待期不重复查询；成功检查结果短期缓存并标明原检查时间。手动检查可以刷新成功缓存，但不会绕过服务端限流等待。

排查时提供当前版本、发行类型、失败阶段和错误文字；`data/toolkit-update-result.json` 保存更新结果，`data/windows-migration-result.json` 保存迁移结果。不要公开账号文件、令牌、词库内容或同步凭据。

## 构建

使用现有 `build-public-release.bat` / `.ps1`，需要支持动态明暗样式的 Inno Setup 6.7+ 编译器。版本来自 `package.json`；Node、安装身份、数据目录、迁移范围和安装界面样式等参数来自根目录 `windows-build.json`，更新超时与缓存参数来自 `toolkit-update.json`。

公开构建从空账号和空快照模板生成两个 ZIP 与两个 Setup。安装器只部署程序及默认模板，不覆盖独立数据目录。工作流已接入 Setup 构建，实际发布仍是单独授权动作。
