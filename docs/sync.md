# WebDAV 同步

在「设置 → 同步与数据」分别选择账号、词库同步；初次使用请为各设备设置相同的同步密码。同步不同于一次性账号文件迁移，也不包含本机登录快照。

**Q: 账号同步需要工具集每天运行吗?**
A: 启用 WebDAV 后，工具集启动、账号增删、词库编辑和自动对齐完成时会同步；运行期间每 15 分钟检查一次，也可点击「立即同步」。关闭工具集期间不执行同步，下次启动再合并各设备的变化。配置保存在本机，密码留空沿用已保存值。

**Q: 两台设备各有不同账号，同步会互相覆盖吗？删除又怎么办？**
A: 按账号 ID 合并。例如 A 有 1、2、3，B 有 7、8、9，各自完成同步后两边都有六个账号；新设备为空不会清空云端。明确删除账号会同步到启用账号同步的其他设备，保留的小型删除记录防止离线旧设备把它加回来；重新收录该账号可恢复。自动刷新凭证不视为重新添加。同一个账号的修改按事件时间合并，设备需保持系统时间准确。这里只移除工具集管理记录，不注销 Typeless 账号。

词库同样合并新增与明确删除。数据没有变化时不会重复上传；有变化时先合并记录，再更新相应的加密文件。账号和词库分别存储，不上传登录快照或整套用户数据。

**Q: WebDAV 会上传什么，安全吗?**
A: 可选仅账号、仅词库或两者。账号同步包含账号 ID、昵称、邮箱、客户端用户 ID、refresh token 和删除记录；词库同步包含词条及其增删记录。两份远端文件独立使用同步密码经 scrypt 派生密钥后以 AES-256-GCM 加密，不上传 access token、设备 ID 或 `profiles/` 登录快照。WebDAV 应用密码和同步密码保存在本机数据目录的受限配置文件中；同步密码遗失后无法恢复远端数据。坚果云可直接使用预设 URL，用户名填邮箱、密码填坚果云生成的应用密码。Google Drive 和 OneDrive 需要各自的 OAuth 接入，不属于通用 WebDAV，本版暂不提供。
