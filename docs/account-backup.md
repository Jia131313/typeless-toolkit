# 账号与备份

「备份与迁移」用一个 JSON 文件携带账号与主词库。账号可选全部或部分，主词库可单独导出，也可随账号一起导出；主词库是工具集共用词库，不按所选账号拆分。备份不是整机镜像，不包含设备配置、登录快照或同步删除记录。含账号的 JSON 带有敏感长期凭证，务必妥善保管。格式规范见 [备份与账号文件格式](account-bundle-format.md)。

**Q: 如何手动刷新当前登录账号?**
A: 点击右上角的账号状态条（或聚焦后按 Enter/空格）。已收录账号只会刷新显示；如果当前账号尚未收录，会直接打开“添加当前账号”窗口。日常检测只读取本地 `app-storage.json`，不会开启调试模式，也不会重启 Typeless。

**Q: token 会过期吗?**
A: Typeless 2.3.1 之后的 access token 约 24 小时有效，refresh token 约 1 年有效。工具集会在需要调用 API 时自动用 refresh token 换取新的 access token，不需要每天打开工具集续签；只有长期 refresh token 也过期或被撤销时，才需要重新登录并点「添加当前账号」。

**Q: 本地备份怎样在另一台电脑恢复？**
A: 在旧电脑打开「设置 → 同步与数据 → 备份与迁移」，点击「导出备份」，选择要迁移的账号并保留主词库选项，保存一个 JSON。在新电脑点击「导入备份」，选择该文件并确认账号、词条预览。账号按 ID 增量合并，词库与本机词条合并，不删除现有账号或词条。新导入的账号需要逐个点击「在此设备启用」，由 Typeless 在新电脑建立登录态与快照。导入入口也识别旧 Account Bundle 和原始 `accounts.json`；旧词库 CSV/TXT 仍可单独导入。账号文件含长期登录凭证，不要上传到公开 Issue。

历史本机副本目录在 Windows 发布版的 `data/backups/`，macOS Tauri 版的 `~/Library/Application Support/Typeless 工具集/data/backups/`。这些历史文件不是新的迁移格式；只需导入其中的账号与词库，不搬运同步元数据。同步删除记录属于运行时协调状态，不是用户导出内容：保留它们可避免已删除账号或词条从另一台设备重新同步回来。需要持续同步账号与主词库时可使用 WebDAV。

兼容工具需要生成账号文件时，参见 [Typeless Account Bundle v1 格式](account-bundle-format.md)。
