# 功能一览

## 这是什么

[Typeless](https://typeless.com/) 是一款语音听写桌面应用(Electron)。本工具集围绕它的几个
实际使用痛点提供本地辅助:

- **多账号管理**:一台机器上切换多个 Typeless 账号,各自保留登录态快照,一键切换。
- **账号跨设备同步**:通过坚果云或其他 WebDAV，在 Windows / macOS 间同步加密的长期登录凭证；新设备可一键建立本机登录态。
- **账号文件导入/导出**:将有效的长期登录凭证导出为标准 JSON，换机或从兼容工具导入时按账号合并，再在新设备启用账号。
- **词库跨账号同步**:把多个账号的个人词库(含系统自动学习的 auto 词)合并成一份主清单,
  再回灌到每个账号,换号不丢词。
- **手动重置设备标识**:在设置中独立处理设备登录问题，不必进入注册向导；普通切号不自动重置。
- **去升级/会员弹窗**:自动定位 Electron 渲染层的付费墙调用并打等长补丁,关掉相关弹窗。
- **安装 Typeless 官方更新**(macOS):校验 Typeless 官方 updater 已下载的本地缓存包,备份当前应用后恢复官方版本与签名；此入口不更新 Typeless Toolkit。

## 功能列表

| 功能 | 入口 | 说明 |
| --- | --- | --- |
| 账号管理 | 管理器 | 添加/移除/切换账号,实时显示额度、词库数、个性化进度、凭证有效期 |
| 账号跨设备同步 | 设置 → 同步与数据 | 通过坚果云或通用 WebDAV 同步 AES-256-GCM 加密的 refresh token；远端账号可在本机一键启用 |
| 概览总览 | 管理器 | 顶部汇总所有账号:账号数、本周额度合计、词库合计、累计节省时长 |
| 词库自动对齐 | 管理器 / CLI | 启动、新增账号和词库编辑后自动触发，另有 15 分钟兜底检查；导出各账号词库到主 CSV,全量对账并分批回灌缺词,回拉后二次校验 |
| 主词库编辑 | 管理器 | 一行一个词,作为所有账号同步的基准,可一键导出 txt；明确删除会同步移除，单次远端缺词不会被误判为删除 |
| 词库导出 | 管理器 | 单账号词库、主词库均可导出为 txt 文件 |
| 账号文件导入/导出 | 设置 → 同步与数据 | 导出有效的长期账号凭证；导入时按账号合并，不覆盖现有账号和本机快照 |
| 本机内部备份 | 设置 → 同步与数据 | 保存账号原始文件、主词库和删除记录到 `backups/时间戳/`；可打开目录，并从旧副本增量导入账号与词库 |
| 搜索 / 排序 | 管理器 | 账号超过 3 个时,按昵称/额度/剩余/词库数排序,支持搜索 |
| 深色模式 | 设置 → 通用 | 跟随系统或手动切换,偏好本地记忆 |
| 注册新账号 | 管理器 | 统一完成保存当前号快照、解除设备限制、登录后抓取真实凭证、跳过教程和后台词库对齐；备注名仅用于本地显示 |
| 重置设备 | 设置 → 权限与维护 | 手动清理设备标识及当前登录态，重启到登录页；保留已保存的账号、快照和词库，不与普通切号联动 |
| 去升级弹窗 | 管理器 | 启动、账号变更和官方更新后自动检查修复；自动定位付费墙调用、处理完整性校验，手动入口仅用于状态查看和重试 |
| 跳过新手引导 | 管理器 | 双写 onboarding 状态并保存到账号快照,切号后自动修复,再重启 Typeless |
| 安装 Typeless 官方更新 | 设置 → 关于与更新(macOS) | 校验 SHA-512、版本、Bundle ID、Developer ID 与 Gatekeeper 后安装 Typeless updater 已下载的本地缓存包,失败自动回滚；不更新 Toolkit |
| 工具集更新 | 设置 → 关于与更新 | 检查 GitHub Release、展示说明并下载 SHA-256 校验包；Windows 退出后自动替换代码且保留 `data/`，macOS 仅打开已校验 DMG 供手动安装 |
